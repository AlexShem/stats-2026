# Семинары по теории вероятностей и математической статистике

НИЯУ МИФИ, осенний семестр 2026. Лекции читает лектор курса; в этом репозитории
собраны материалы к семинарским занятиям, которые веду я.

**Расписание.** 16 семинаров по четвергам, с 3 сентября по 17 декабря 2026.
Полное расписание с темами — в `index.qmd` (собирается в `_output/index.html`).

## Два вида материалов из одного источника

Каждый семинар — это один файл `seminars/NN-slug/seminar-NN.qmd`, который
собирается в двух видах:

| Что | Команда | Результат |
|:--|:--|:--|
| Конспект для подготовки: решения, выкладки, код, заметки к занятию | `make prep N=01` | `_output/.../seminar-01.html` |
| Раздатка для студентов: только условия задач, для печати | `make handout N=01` | `_output/.../seminar-01.pdf` |

Различие даёт профиль Quarto `prep`. Всё, что обёрнуто в

```markdown
::: {.content-visible when-profile="prep"}
::: {.solution}
…решение…
:::
:::
```

попадает в HTML-конспект и **не попадает** в студенческий PDF. Так условия задач
и их разборы живут рядом в одном файле и не расходятся.

## Начало работы

```bash
uv sync                 # окружение (Python 3.14) и зависимости
make new N=02 SLUG=conditional-probability   # новый семинар из шаблона
make prep N=02          # собрать конспект и открыть в браузере
make handout N=02       # собрать PDF для студентов
make all                # весь проект целиком
```

Требуется [Quarto](https://quarto.org) ≥ 1.10 и TeX Live с LuaLaTeX
(`quarto install tinytex`).

## Структура

```
index.qmd                   расписание семестра и обзор репозитория
_quarto.yml                 общие настройки; формат PDF-раздатки
_quarto-prep.yml            профиль prep: HTML с решениями
_templates/seminar.qmd      шаблон нового семинара
seminars/NN-slug/           материалы одного семинара
lectures/                   конспекты лекций, на которые опираются задачи
src/mephi_stats/            общий Python: оформление графиков, расписание
references.bib              литература курса
```
