# Семинары по теории вероятностей и математической статистике

НИЯУ МИФИ, осенний семестр 2026. Лекции читает лектор курса; здесь собраны
материалы к семинарским занятиям.

**Расписание.** 16 семинаров по вторникам, с 8 сентября по 22 декабря 2026.
Полное расписание с темами: в книге.

## Что собирается из репозитория

Каждый семинар: один файл `seminars/NN-slug/seminar-NN.qmd`, из которого
получаются два документа для студентов:

| Что | Команда | Результат |
|:--|:--|:--|
| Книга: теория, задачи, решения в свёрнутых блоках, примеры на Python | `make book` | `_output/book/index.html` |
| Раздатка: сводка, условия задач и домашнее задание, для печати | `make handout N=01` | `_output/handouts/seminars/.../seminar-01.pdf` |

Всё, что обёрнуто в

```markdown
::: {.content-hidden when-profile="handout"}
::: {.callout-tip collapse="true" title="Решение"}
…решение…
:::
:::
```

попадает в книгу и **не попадает** в раздатку (профиль Quarto `handout`).

Код в главах пишется явно: все импорты и функции главы собраны в первой ячейке
раздела «Код для этой главы», ниже новых функций не появляется. Это проверяет
`tests/test_chapters.py`.

## Начало работы

```bash
uv sync                                   # окружение (Python 3.14) и зависимости
make new N=03 SLUG=random-variables       # новая глава из шаблона
make preview                              # книга с автообновлением
make handouts                             # все PDF-раздатки
make all                                  # книга и раздатки
make test lint                            # тесты и проверка стиля
```

Новую главу нужно добавить в `book.chapters` в `_quarto.yml`.

Требуется [Quarto](https://quarto.org) ≥ 1.10 и TeX Live с LuaLaTeX
(`quarto install tinytex`).

## Структура

```

book.scss                   оформление книги
_templates/                 шаблон главы и пример

problems/                   (только локально, в git нет) банк задач Гмурмана
lectures/                   (только локально, в git нет) конспекты лекций
src/mephi_stats/            расписание семестра
tests/                      тесты расписания и правил оформления глав
```
